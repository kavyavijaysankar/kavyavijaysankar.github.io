This started as a project during my final year of undergraduate studies at Christ University. I wrote the entire game in a single Python script using the PyGame library. The Idea was to have players play on the same team rather than against each other. This type of gameplay is called co-operative play. This game took inspiration from other 2-player cooperative games such as Fireboy and Watergirl, and It Takes Two. The game is a proof-of-concept, not a clinical tool. I keep adding more levels as and when I get time. 

Check out the GitHub repository to inspect the code and for more information on the levels. You can also play the game by clicking on the Game link above. Hope you like it!
