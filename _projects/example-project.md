Copy this file to add a new project — one Markdown file per project, any filename you like.
The file's name becomes its URL, so `spike-sorting.md` is published at `/projects/spike-sorting/`.

Only `collection: projects` is required; it's what makes the entry appear on the index page.
`title` and `excerpt` control how it's listed. The `excerpt` accepts HTML, which is how the
thumbnail above is included — point it at your own image in `/images/`, or drop the `<img>`
tag for a text-only entry.

Everything below the front matter is the project's own page: write as much or as little as
you want, in Markdown.
